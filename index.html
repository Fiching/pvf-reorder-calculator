How the reorder calculation works
Target = Avg Monthly Demand × (Target Months + Safety Months)
Position = On Hand + On PO − On BO
Order Qty = MAX(0, Target − Position), rounded up to PPQ

UOM auto-detect: The tool derives effective unit cost from the system's extended amounts, so pipe priced per 100 ft (UOM=C) calculates correctly without a separate column.

Smart Filter rules: Slow & cheap (demand ≤ threshold AND cost < threshold) runs first, then minimum line value. Skipped items show a skip badge when "All matched items" is selected.

How the DRR list is built

Disposition pool: Items you shouldn't be stocking that still have inventory on the shelf. By default this is anything with Tier = NS/TRN/OBS and On Hand > 0. If "Include System-Flagged" is on, the pool also picks up items with system-calculated inefficient quantity (Inefficient Qty - NQ > 0).

DRR eligibility (all three must be true):

Replen Whse = Hub (default 423)
Extended Value > Min Threshold (default $50)
On Hand > 0

Items failing any of these fall through to the Costing tab with the reason shown. The two tabs together account for every item in the disposition pool.

Costing · Scrap / Write-Off

Items in the disposition pool that can't be DRR'd — either the wrong replen hub, below the minimum value threshold, or no replen warehouse at all. These get scrapped or disposed. The DRR tab settings control both lists; this page shows what falls through.

How the Costing list is built

Every item here is in the disposition pool but fails DRR eligibility. The Reason column shows which rule caught it:

   • Wrong hub — replen warehouse is something other than the configured hub (5422, 1789, 986, etc.)

   • No replen whse — no replen warehouse assigned, nowhere to send it back

   • Below threshold — extended value is under the DRR minimum; not worth the paperwork

Lines here represent real dollar loss — you're writing this value off. Worth scanning periodically for patterns (e.g., repeat customer SPs never picked up) so you can prevent the same issue next time.
