How the reorder calculation works
Target = Avg Monthly Demand × (Target Months + Safety Months)
Position = On Hand + On PO − On BO
Order Qty = MAX(0, Target − Position), rounded up to PPQ

UOM auto-detect: The tool derives effective unit cost from the system's extended amounts, so pipe priced per 100 ft (UOM=C) calculates correctly without a separate column.

Smart Filter rules: Slow & cheap (demand ≤ threshold AND cost < threshold) runs first, then minimum line value.

How sourcing works

Inputs: The current Reorder list (items where Order Qty > 0) crossed with inventory at every uploaded warehouse. With only one file uploaded, the tool falls back to the DC OHB column to give partial visibility.

Routing priority:

   1. Hub (423) — anything available at the primary hub goes here, since the weekly hub truck carries it without freight charges.

   2. Other DCs — remaining items grouped by which DC has them, with DCX FFA progress shown. Items below the threshold need either more lines added or freight will apply.

   3. External — items with no DC stock anywhere. These need vendor-direct orders or alternate sourcing.

DCX FFA mapping: Linebuys from the DCX Special Shipping Instructions document are embedded. $500 tier (Aquatherm, Viega, NUPI, FNW copper press, Nibco fittings), $1,500 tier (Carbon/Stainless Steel Weld Fittings, Tyco Fire, Victaulic, Jones Stephens, OMB, IMI, DuraStar, GroovJoint), $0.01 tier (Warren, DSI CS, Avallon Range/Ice). Linebuys not on the approved list are flagged "freight will apply."

How the DRR list is built

Disposition pool: Items you shouldn't be stocking that still have inventory. By default Tier = NS/TRN/OBS with On Hand > 0, plus optionally system-flagged inefficient items.

DRR eligibility: Replen Whse = Hub AND Extended Value > threshold AND On Hand > 0.

Items failing any check fall through to the Costing tab.
